Using guidance

Zulqarnain Statistical Tools is designed to work like R software, but through a simple web interface. Follow these steps to analyse your experimental data and download publication‑ready outputs.

Step 1 – Prepare your data file

  • Organise your data in Excel (.xlsx) or CSV (.csv) format.
  • Use clear column names (for example: Treatment, Replication, Yield, Height).
  • Each row should represent one observation / experimental unit.
  • Remove empty rows and columns, and avoid merged cells or formulas.

Step 2 – Choose the appropriate tool

  • ANOVA: one‑way, two‑way, CRD, RCBD, augmented block design, simple ANOVA, Line × Tester, Diallel, mean comparison tests.
  • t‑test: comparison of two means (paired or independent samples).
  • Descriptive statistics: mean, standard deviation, standard error, minimum, maximum, coefficient of variation, etc.
  • Multivariate analysis: PCA (with biplot, scree plot and tables), cluster analysis (dendrogram and cluster tables), correlation matrix, heatmaps, path analysis with tree diagrams, and other graphs.

Step 3 – Upload your dataset

  • Click the menu item for the analysis you want (e.g. ANOVA Analysis or Multiple Analysis).
  • Use the Browse / Upload button to select your Excel or CSV file.
  • Select the correct sheet (for Excel files) and confirm the column names detected by the tool.

Step 4 – Set analysis options

  • Choose the response variable(s) and factor(s) (e.g. treatment, replication, year, location).
  • For ANOVA, select the experimental design (CRD, RCBD, augmented, Line × Tester, Diallel, etc.).
  • For PCA, cluster analysis, correlation or path analysis, choose the traits to include in the multivariate model.
  • Adjust optional settings such as significance level (α), type of mean comparison test, distance measure for clustering, etc.

Step 5 – Run the analysis

  • Click the Run or Analyse button for the chosen method.
  • The server will process your data using R, and results will appear on the screen as:
    • ANOVA tables, error terms, F‑values and p‑values,
    • t‑test or mean comparison tables,
    • PCA tables, eigenvalues, loadings, biplots and scree plots,
    • Cluster tables and dendrogram plots,
    • Correlation matrices, heatmaps and path diagrams.

Step 6 – Download tables and graphs

  • Use the Download table buttons to save results as Excel files for further editing or reporting.
  • Use the Download plot buttons to save figures as 300 dpi PNG images suitable for theses, presentations or journal publications.

Step 7 – Interpret and report your results

  • Interpret F‑values, p‑values, mean comparisons and multivariate patterns just as you would in R.
  • Always cross‑check the assumptions of the methods (normality, homogeneity of variance, independence, etc.).
  • When using these results in publications, theses or reports, please give proper credit to Zulqarnain Statistical Tools (see Terms and Conditions below).

Questions & Answers (FAQ)

1. What type of data files can I upload?

You can upload datasets in Excel (.xlsx) or comma‑separated values (.csv) format. Each row should represent one observation or plot, and each column should represent a variable (e.g. treatment, replication, trait values). Avoid merged cells, formulas and special characters in column names.

2. Are the results equivalent to running the same analysis in R?

Yes. Zulqarnain Statistical Tools is built on the R programming language and uses standard statistical packages. The ANOVA, t‑tests, descriptive statistics, PCA, cluster analysis, correlation, heatmaps, path analysis and other outputs are generated using the same methods as in R, so numerical results should match R (given the same data and options).

3. Which statistical analyses are currently supported?

The platform supports a wide range of experimental design and multivariate tools, including:

  • ANOVA: one‑way and two‑way ANOVA; CRD, RCBD, augmented block design; simple ANOVA; Line × Tester; Diallel; and mean comparison tests.
  • Classical inference: t‑tests and descriptive statistics.
  • Multivariate analysis: PCA with biplot, scree plot and tables; cluster analysis with dendrogram and cluster membership tables; correlation analysis; heatmaps; and path analysis with tree‑like plots.

4. Is my uploaded data stored on the server?

Uploaded files are used temporarily for the analysis and are not intentionally stored as a permanent database. However, as with any web service, some technical logs may be kept for security and performance monitoring. Do not upload data that is confidential, personally identifiable, or sensitive. You are responsible for anonymising data before upload if required by your institution or ethics guidelines.

5. Is Zulqarnain Statistical Tools free to use?

Yes, the tools are currently provided free of charge for educational and research purposes. However, the service is offered “as is”, without any guarantee of availability, accuracy or fitness for a particular purpose. The developer may change, restrict or discontinue the service at any time.

6. How should I acknowledge or cite this website in my thesis or publication?

When you use results, tables or plots generated by this website in theses, reports or journal articles, please give proper credit. A suggested acknowledgement is:

“Statistical analyses (ANOVA, multivariate analysis and graphics) were performed using Zulqarnain Statistical Tools (https://zulqarnainm656-maker.github.io/).”

You may adapt the wording according to the style of your journal, but an explicit reference to Zulqarnain Statistical Tools is required (see Terms and Conditions).

7. What should I do if I get an error or strange output?

First, re‑check your data file: correct column names, no missing factor levels, no empty rows, and correct design selection (CRD, RCBD, augmented, Line × Tester, etc.). If the problem persists, repeat the analysis with a small subset of the data or compare with R. You can also contact the developer via the Contact page, including a short description of the problem and (if possible) a simplified example dataset.
