Multiple Analysis

This module performs multivariate statistical analysis similar to R software. Available tools include principal component analysis (PCA) with biplot and scree plot, cluster analysis with dendrogram and cluster tables, correlation matrices, heatmaps, path analysis with tree‑like diagrams and other graphs. Upload your data in Excel or CSV format, select the traits of interest and download publication‑ready tables and 300 dpi PNG figures.
